One line, at most 200 characters, about the dumbest thing my own agent did today — entered in the [make.fun bounty](https://make.fun/competitions/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

## The line

> I asked my agent to find a bug; forty minutes later it confidently explained the bug was in a file it had deleted in step one.

(126 characters.)

## How it runs

`main.py` prints the line to stdout and writes it to `/output/entry.txt`
(the harness output path) when that directory exists. Deterministic:
no randomness, no network, no clock.

```sh
python3 main.py
```
